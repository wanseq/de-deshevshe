# Де дешевше? — публікація і нічне оновлення

Сайт порівняння цін АТБ, Сільпо та Фоззі. Показує лише товари, наявні щонайменше у двох магазинах. Готовий до розміщення на GitHub Pages.

## Опублікувати один раз

1. Створіть **публічний** репозиторій на GitHub, наприклад `de-deshevshe`, з гілкою `main`. На безплатному тарифі GitHub Pages для цього сценарію працює з публічним репозиторієм.
2. Покладіть **вміст** цього архіву в корінь репозиторію. Папку `.github` також треба додати: там автоматизація. Найзручніше через GitHub Desktop: File → Add local repository (якщо папка ще не репозиторій, Create a Repository), опублікувати його на GitHub із вимкненим прапорцем «Keep this code private». Або скористайтеся командами Git нижче.
3. У репозиторії відкрийте **Settings → Pages → Build and deployment → Source → GitHub Actions**.
4. Відкрийте вкладку **Actions**. Запуск після першого `push` опублікує готовий `products.js`. Адреса: `https://ВАШ-ЛОГІН.github.io/de-deshevshe/` (підставте ваш логін і точну назву репозиторію). Дочекайтеся зеленої позначки запуску.
5. В Actions → `Publish site and refresh prices` → `Run workflow` запустіть збір вручну один раз, щоб перевірити доступ парсерів до магазинів з GitHub.

Приклад команд Git у папці з розпакованим архівом (замініть логін та назву репозиторію):

```bash
git init -b main
git add .
git commit -m "Publish grocery price comparison"
git remote add origin https://github.com/ВАШ-ЛОГІН/de-deshevshe.git
git push -u origin main
```

## Що відбувається щоночі

GitHub Actions о **03:37 за часом Києва** запускає три парсери, перевіряє, що каталоги повні, збирає `products.js` і публікує чотири файли сайту. На літній/зимовий час розклад перемикається автоматично. Оновлення не потребує вашого ввімкненого комп'ютера. Сайт показує дату збору товарів. Розклад GitHub може стартувати із затримкою.

Якщо магазин не відповів або товарів стало аномально мало, запуск завершується помилкою **до публікації** — попередня версія сайту лишається доступною. Перевіряйте вкладку Actions після першого ручного запуску та при помилках. Якщо парсер перестане розуміти сторінку магазину, його доведеться оновити.

У публічних репозиторіях GitHub може відключити заплановані запуски після 60 днів без активності репозиторію. Перевіряйте вкладку Actions; заплановану автоматизацію можна знову ввімкнути там або оновити файл розкладу комітом. Збір не гарантує цін і наявності в конкретному фізичному магазині: сайти магазинів можуть показувати мережеві/онлайн-ціни.

## Оновити код вручну

При зміні `index.html`, `style.css`, `app.js` або `products.js` зробіть commit і push у `main` — це відразу опублікує наявний каталог без повторного парсингу. Щоб оновити ціни поза розкладом, натисніть `Run workflow` у вкладці Actions.
